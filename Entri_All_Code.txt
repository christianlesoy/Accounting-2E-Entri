# Entri

Entri is a native JavaFX accounting desktop application backed by Supabase
PostgreSQL. It uses plain `javac`/`java`; no Maven or Gradle build is required.

## Requirements

- JDK 21
- JavaFX SDK for JDK 21
- A Supabase project
- PostgreSQL JDBC driver

Install JDK 21 from an OpenJDK distribution, download the JavaFX SDK for JDK 21
from [Gluon](https://gluonhq.com/products/javafx/), and download the latest
PostgreSQL JDBC driver from
[jdbc.postgresql.org](https://jdbc.postgresql.org/download/).
Extract the JavaFX SDK to `C:\javafx-sdk-21` and copy the driver jar to
`lib\postgresql-42.7.14.jar` (create `lib` if needed). These jars remain local
and are excluded from Git.

The launch scripts expect JavaFX at `C:\javafx-sdk-21\lib` and the PostgreSQL
driver at `lib\postgresql-42.7.14.jar`. Edit the script variables if you
installed them elsewhere. The launcher selects an installed JDK 21 so the
JavaFX runtime matches its supported Java version. If JDK 21 is installed in a
custom location, set `ENTRI_JDK_HOME` to its installation folder before
launching. Keep dependency jars out of source control.

## VS Code Java setup

The project includes `.vscode/settings.json` so the Java extension uses
`src/main/java` as its source root and can find JavaFX and the PostgreSQL driver.
Install the Java Extension Pack, JDK 21, and JavaFX at
`C:\javafx-sdk-21\lib` as described above. If you install JavaFX elsewhere,
update its path in `.vscode/settings.json`. After opening the project folder,
run **Java: Clean Java Language Server Workspace** from the Command Palette if
old red error markers remain, then reload the window.

## Add the Entri logo

The app logo is stored at `src\main\resources\images\logo.png`. The launcher
copies files in `src\main\resources` into the compiled application. The image
appears on the login screen, navigation sidebar, top toolbar, and application
window icon.

## Supabase database setup

1. Create a project at [supabase.com](https://supabase.com/dashboard). Save the
   database password you choose; it is different from your Supabase account
   password.
2. In your project, open **SQL Editor**, paste the contents of
   `database/entri_schema.sql`, and run it. This creates Entri's PostgreSQL
   tables. Running the script again is safe and does not erase rows.
3. Open **Connect** in the project dashboard and choose **Session pooler**.
   Copy the host, port, database name, and username shown there. Session mode
   supports this app's JDBC prepared statements and works on IPv4 networks.
   Supabase's [PostgreSQL connection guide](https://supabase.com/docs/guides/database/connecting-to-postgres)
   describes the connection options and where to find them.
4. Set the connection details in the PowerShell terminal before running Entri.
   Replace the example values with the values from **Connect**:

   ```powershell
   $env:ENTRI_DB_URL = "jdbc:postgresql://YOUR-POOLER-HOST:5432/postgres?sslmode=require"
   $env:ENTRI_DB_USER = "postgres.YOUR-PROJECT-REF"
   ```

   You can also copy `config.example.properties` to `config.properties` and
   put the non-secret URL and username there. Environment variables take
   precedence, and `config.properties` is excluded from Git.
5. Run the launcher. If `ENTRI_DB_PASSWORD` is not set, it securely prompts for
   the Supabase database password without echoing it. Do not place that password
   in Java source, `config.properties`, or committed files.

The app connects to hosted PostgreSQL over TLS through the session pooler using
the database username and password. For this first-project setup, it keeps Entri's
existing app-level login and ownership checks. Those are not Supabase Auth or
database-enforced row-level security; do not use this design for sensitive or
production data. Supabase explains the distinctions in its
[data security guide](https://supabase.com/docs/guides/database/secure-data).
The schema creates a fresh online database; it does not migrate any data from
your previous local MySQL database.

## Currency display preference

After signing in, hover over **My Account** in the top-right menu and click
**Currency display** to choose PHP (₱) or USD ($). The choice is saved for that
user in Supabase and is loaded at the next sign-in. It changes only the displayed
symbol and formatting; it does not convert or change saved amounts or the
currency codes recorded on journal entries. The Journal Entry and Ledger
currency columns show the selected symbol in a compact width, while totals and
worksheet rows remain grouped by each record's saved currency code. New journal
entries start with the selected currency code; editing an existing entry keeps
its saved code.

## Compile and run on Windows

Open PowerShell in this folder and run:
```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run.ps1
```

If `ENTRI_DB_PASSWORD` is not already set, the script securely prompts for the
Supabase database password without echoing it. The first compilation creates
`out`. Use `run.bat` from Command Prompt to start the same PowerShell launcher
and password prompt.

To view the interface without logging in or connecting to Supabase, launch the
sample-data, read-only preview:


Set `ENTRI_JDK_HOME` to the JDK 21 installation folder first if it is not
already set. The launcher script detects standard JDK 21 installations
automatically.

The login screen also includes an **Explore a sample preview** button. The
dashboard preview follows the desktop layout: Journal Entry and Ledger cards
side by side, a grouped 12-column worksheet below, then Recent Views with
View/Edit actions. Table totals are shown at the bottom; sample data is
illustrative only and is never saved. The profile menu and Developers page are
available in preview mode as well.

Equivalent manual commands (PowerShell):

```sh
java --module-path "$FX_LIB" --add-modules javafx.controls -cp "out:lib/postgresql-42.7.14.jar" main.java.com.entri.MainApp
```

Run the dependency-free password, accounting-validation, currency-formatting,

## Features and accounting behavior

- The JavaFX window can resize from a practical 720-by-520 minimum; toolbars
  and filters wrap, the sidebar scales with the window and can be collapsed,
  and dashboard cards change columns at narrower widths. On wide dashboards,
  Journal Entry and Ledger share the first row; the grouped 12-column Worksheet
  and Recent Views each occupy a full-width row below. The header keeps
  branding, Home/new-entry actions, and profile controls in aligned sections,
  switching to compact labels when needed. Accounting tables fill available
  space, while the 12-column worksheet keeps its own horizontal scrollbar on
  narrow windows.
- User registration/login uses salted PBKDF2-HMAC-SHA256 password hashes.
- Each new user receives a basic chart of accounts.
- Journal transactions support multiple debit and credit lines. A balanced
  transaction must have equal, positive debit and credit totals before posting.
- Dashboard cards show saved journal entries, actual ledger rows, a worksheet
  preview, and user-specific recent items; no sample financial transactions
  or balances are generated.
- Recent journal entries, ledger accounts, and worksheets are recorded in
  Supabase PostgreSQL for the authenticated user. Updating an email address
  requires the current password.
- Ledger balances add debits and subtract credits for assets/expenses, and
  subtract debits and add credits for liabilities/equity/revenue. Running
  balances and worksheet rows are kept separate by currency; no exchange-rate
  conversion is implied.
- The worksheet derives its trial balance and adjustment columns from saved
  journal entries within the selected period. Adjusted trial balance is their
  sum; income statement and balance sheet columns classify adjusted balances
  by account type. Net income/loss is carried to equity and the balance sheet.
  The balance indicator checks each relevant section by currency. This is an
  unaudited working worksheet, not a statutory financial statement.
- Entries, lines, and ledger accounts are always queried within the logged-in
  user's ownership scope.
- Journal Entry provides Add, View, Edit, and selection-aware Delete actions.
  Search and date filters can be cleared separately from Refresh, which keeps
  the active filters.
- Ledger and the 12-column Worksheet provide account Add, Edit, and Delete
  actions. Editing keeps the account ID so existing journal links remain valid;
  changing classification is blocked when posted activity exists, and deleting
  an account with journal lines is refused rather than cascading financial data.
- `Ctrl+N` opens a new journal entry. `Ctrl+F` focuses search on Journal Entry,
  Ledger, or Recent Views; from the dashboard it opens Journal Entry search.

## Main classes

- `MainApp` owns login/registration, navigation, and the in-memory user session.
- `src/main/java/main/java/com/entri/MainApp.java` is the only application
  launcher. The test classes have their own `main` methods solely so `test.ps1`
  can run the checks without an additional test framework. Compiled `.class`
  files under `out` are generated by `run.ps1`; they are not duplicate sources.
- `Database` validates environment configuration and creates JDBC connections.
- `UserRepository` and `AccountingRepository` contain persistence operations.
- `AuthService` handles validation and password hashing.
- `AccountingService` validates and saves balanced journal entries.
- `JournalLine` models individual debit/credit lines; `JournalEntry` groups
  lines into a balanced, dated transaction.
- `AccountingSection` provides the shared JavaFX section contract;
  `JournalEntrySection`, `LedgerSection`, and `WorksheetSection` implement it.
- `EntriTheme` centralizes the desktop palette and reusable styles.
- `OverviewSection` and `RecentViewsSection` display current user-specific data.
- `DeveloperInfo` holds clearly editable placeholder team information.

## Troubleshooting

- **Cannot connect:** verify the Supabase project is running, the SQL schema was
  created, the session-pooler host/port/user are correct, and
  `ENTRI_DB_PASSWORD`. The application shows a safe connection error without
  exposing credentials.
- **JavaFX modules missing:** point `FX_LIB`/the PowerShell script at the `lib`
  folder of a JavaFX SDK compatible with your JDK.
- **JDBC driver missing:** place the PostgreSQL driver at
  `lib\postgresql-42.7.14.jar` or
  update the classpath in the launch script.
- **Access denied:** verify the database username and password from the
  Supabase project's **Connect** panel.

$ErrorActionPreference = "Stop"
Set-Location $PSScriptRoot
$FxLib = if ($env:FX_LIB) { $env:FX_LIB } else { "C:\javafx-sdk-21\lib" }
$JdkHome = $env:ENTRI_JDK_HOME
if ([string]::IsNullOrWhiteSpace($JdkHome)) {
    $JdkHome = Get-ChildItem -Path (Join-Path $env:ProgramFiles "Java") `
        -Directory -Filter "jdk-21*" -ErrorAction SilentlyContinue |
        Sort-Object Name -Descending |
        Select-Object -First 1 -ExpandProperty FullName
}
$Driver = "lib\postgresql-42.7.14.jar"

if ([string]::IsNullOrWhiteSpace($JdkHome) -or
        -not (Test-Path (Join-Path $JdkHome "bin\java.exe")) -or
        -not (Test-Path (Join-Path $JdkHome "bin\javac.exe"))) {
    throw "JDK 21 was not found. Install JDK 21 or set ENTRI_JDK_HOME to its installation folder."
}
if (-not (Test-Path "$FxLib\javafx.controls.jar")) {
    throw "JavaFX SDK was not found at '$FxLib'. Set FX_LIB to its lib folder."
}
if (-not (Test-Path $Driver)) {
    throw "PostgreSQL JDBC driver was not found at '$Driver'. Download it from https://jdbc.postgresql.org/download/."
}
$PromptedPassword = $false
if ([string]::IsNullOrWhiteSpace($env:ENTRI_DB_PASSWORD)) {
    $SecurePassword = Read-Host "Enter your Supabase database password" -AsSecureString
    if ($SecurePassword.Length -eq 0) {
        throw "The Supabase database password cannot be empty."
    }
    $PasswordPointer = [Runtime.InteropServices.Marshal]::SecureStringToBSTR($SecurePassword)
    try {
        $env:ENTRI_DB_PASSWORD = [Runtime.InteropServices.Marshal]::PtrToStringBSTR($PasswordPointer)
    }
    finally {
        [Runtime.InteropServices.Marshal]::ZeroFreeBSTR($PasswordPointer)
        $SecurePassword.Dispose()
    }
    $PromptedPassword = $true
}

try {
    New-Item -ItemType Directory -Force -Path out | Out-Null
    $Sources = Get-ChildItem -Recurse -Path src\main\java -Filter *.java | ForEach-Object { $_.FullName }
    & (Join-Path $JdkHome "bin\javac.exe") --release 21 --module-path $FxLib --add-modules javafx.controls -cp $Driver -d out $Sources
    if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }
    if (Test-Path src\main\resources) {
        Copy-Item -Path src\main\resources\* -Destination out -Recurse -Force
    }
    & (Join-Path $JdkHome "bin\java.exe") --enable-native-access=javafx.graphics --module-path $FxLib --add-modules javafx.controls -cp "out;$Driver" main.java.com.entri.MainApp
    exit $LASTEXITCODE
}
finally {
    if ($PromptedPassword) { Remove-Item Env:ENTRI_DB_PASSWORD -ErrorAction SilentlyContinue }
}

package main.java.com.entri;

import java.sql.*;
import java.util.ArrayList;
import java.util.List;

final class AccountingRepository {
    List<Account> accounts(long userId) throws SQLException {
        List<Account> result = new ArrayList<>();
        try (Connection c = Database.getConnection();
             PreparedStatement p = c.prepareStatement(
                     "SELECT id,account_code,account_name,account_type FROM ledger_accounts WHERE user_id=? ORDER BY account_code")) {
            p.setLong(1, userId);
            try (ResultSet r = p.executeQuery()) {
                while (r.next()) result.add(new Account(r.getLong(1), r.getString(2), r.getString(3), r.getString(4)));
            }
        }
        return result;
    }

    Account addAccount(long userId, String code, String name, String type) throws SQLException {
        String sql = "INSERT INTO ledger_accounts(user_id,account_code,account_name,account_type) "
                + "VALUES(?,?,?,?) RETURNING id";
        try (Connection connection = Database.getConnection();
             PreparedStatement statement = connection.prepareStatement(sql)) {
            statement.setLong(1, userId);
            statement.setString(2, code);
            statement.setString(3, name);
            statement.setString(4, type);
            try (ResultSet result = statement.executeQuery()) {
                if (!result.next()) throw new SQLException("The new account ID was not returned.");
                return new Account(result.getLong(1), code, name, type);
            }
        } catch (SQLException ex) {
            if ("23505".equals(ex.getSQLState())) {
                throw new IllegalArgumentException("That account code or account name is already in use.", ex);
            }
            throw ex;
        }
    }

    Account updateAccount(long userId, long accountId, String code, String name, String type)
            throws SQLException {
        try (Connection connection = Database.getConnection()) {
            connection.setAutoCommit(false);
            try {
                String existingType;
                try (PreparedStatement statement = connection.prepareStatement(
                        "SELECT account_type FROM ledger_accounts WHERE id=? AND user_id=? FOR UPDATE")) {
                    statement.setLong(1, accountId);
                    statement.setLong(2, userId);
                    try (ResultSet result = statement.executeQuery()) {
                        if (!result.next()) throw new SQLException("The account was not found for this user.");
                        existingType = result.getString(1);
                    }
                }

                if (!existingType.equals(type)) {
                    try (PreparedStatement statement = connection.prepareStatement(
                            "SELECT EXISTS(SELECT 1 FROM journal_entry_lines WHERE ledger_account_id=?)")) {
                        statement.setLong(1, accountId);
                        try (ResultSet result = statement.executeQuery()) {
                            if (result.next() && result.getBoolean(1)) {
                                throw new IllegalArgumentException(
                                        "This account has posted journal activity. Its classification cannot be changed because that would reclassify historical balances.");
                            }
                        }
                    }
                }

                try (PreparedStatement statement = connection.prepareStatement(
                        "UPDATE ledger_accounts SET account_code=?,account_name=?,account_type=? "
                                + "WHERE id=? AND user_id=?")) {
                    statement.setString(1, code);
                    statement.setString(2, name);
                    statement.setString(3, type);
                    statement.setLong(4, accountId);
                    statement.setLong(5, userId);
                    if (statement.executeUpdate() != 1) {
                        throw new SQLException("The account could not be updated.");
                    }
                }
                connection.commit();
                return new Account(accountId, code, name, type);
            } catch (SQLException | RuntimeException ex) {
                connection.rollback();
                throw ex;
            }
        } catch (SQLException ex) {
            if ("23505".equals(ex.getSQLState())) {
                throw new IllegalArgumentException("That account code or account name is already in use.", ex);
            }
            throw ex;
        }
    }

    void removeAccount(long userId, long accountId) throws SQLException {
        String sql = "DELETE FROM ledger_accounts a WHERE a.id=? AND a.user_id=? "
                + "AND NOT EXISTS (SELECT 1 FROM journal_entry_lines l WHERE l.ledger_account_id=a.id)";
        try (Connection connection = Database.getConnection();
             PreparedStatement statement = connection.prepareStatement(sql)) {
            statement.setLong(1, accountId);
            statement.setLong(2, userId);
            if (statement.executeUpdate() == 1) return;
        }

        try (Connection connection = Database.getConnection();
             PreparedStatement statement = connection.prepareStatement(
                     "SELECT EXISTS(SELECT 1 FROM ledger_accounts WHERE id=? AND user_id=?)")) {
            statement.setLong(1, accountId);
            statement.setLong(2, userId);
            try (ResultSet result = statement.executeQuery()) {
                if (!result.next() || !result.getBoolean(1)) {
                    throw new SQLException("The account was not found for this user.");
                }
            }
        }
        throw new IllegalArgumentException(
                "This account has posted journal lines and cannot be removed. Its accounting history is preserved.");
    }

    JournalEntry getEntry(long userId, long entryId) throws SQLException {
        String sql = "SELECT id,entry_date,particulars,currency,entry_type FROM journal_entries WHERE user_id=? AND id=?";
        try (Connection c = Database.getConnection(); PreparedStatement p = c.prepareStatement(sql)) {
            p.setLong(1, userId);
            p.setLong(2, entryId);
            try (ResultSet r = p.executeQuery()) {
                if (!r.next()) return null;
                long id = r.getLong(1);
                java.time.LocalDate date = r.getDate(2).toLocalDate();
                String particulars = r.getString(3);
                String currency = r.getString(4);
                String entryType = r.getString(5);
                List<JournalLine> lines = new ArrayList<>();
                String lineSql = "SELECT a.id,a.account_code,a.account_name,a.account_type,l.debit,l.credit "
                        + "FROM journal_entry_lines l JOIN ledger_accounts a ON a.id=l.ledger_account_id "
                        + "WHERE l.journal_entry_id=? AND a.user_id=? ORDER BY l.id";
                try (PreparedStatement lineQuery = c.prepareStatement(lineSql)) {
                    lineQuery.setLong(1, id);
                    lineQuery.setLong(2, userId);
                    try (ResultSet lineRows = lineQuery.executeQuery()) {
                        while (lineRows.next()) {
                            Account account = new Account(lineRows.getLong(1), lineRows.getString(2),
                                    lineRows.getString(3), lineRows.getString(4));
                            lines.add(new JournalLine(account, lineRows.getBigDecimal(5), lineRows.getBigDecimal(6)));
                        }
                    }
                }
                return new JournalEntry(id, date, particulars, currency, entryType, lines);
            }
        }
    }

    List<JournalEntry> entries(long userId, String filter) throws SQLException {
        return entries(userId, filter, null, null);
    }

    List<JournalEntry> entries(long userId, String filter, java.time.LocalDate from, java.time.LocalDate to)
            throws SQLException {

    long saveEntry(long userId, JournalEntry entry) throws SQLException {
        try (Connection c = Database.getConnection()) {
            c.setAutoCommit(false);
            try {
                verifyOwnedAccounts(c, userId, entry.getLines());
                long id = entry.getId();
                if (id > 0) {
                    try (PreparedStatement p = c.prepareStatement(
                            "UPDATE journal_entries SET entry_date=?,particulars=?,currency=?,entry_type=?,"
                                    + "updated_at=CURRENT_TIMESTAMP WHERE id=? AND user_id=?")) {
                        p.setDate(1, Date.valueOf(entry.getDate()));
                        p.setString(2, entry.getParticulars());
                        p.setString(3, entry.getCurrency());
                        p.setString(4, entry.getType());
                        p.setLong(5, id);
                        p.setLong(6, userId);
                        if (p.executeUpdate() != 1) throw new SQLException("Journal entry not found for this account.");
                    }
                    try (PreparedStatement p = c.prepareStatement(
                            "DELETE FROM journal_entry_lines WHERE journal_entry_id=? "
                                    + "AND EXISTS (SELECT 1 FROM journal_entries j WHERE j.id=? AND j.user_id=?)")) {
                        p.setLong(1, id);
                        p.setLong(2, id);
                        p.setLong(3, userId);
                        p.executeUpdate();
                    }
                } else {
                    try (PreparedStatement p = c.prepareStatement(
                            "INSERT INTO journal_entries(user_id,entry_date,particulars,currency,entry_type) VALUES(?,?,?,?,?)",
                            Statement.RETURN_GENERATED_KEYS)) {
                        p.setLong(1, userId);
                        p.setDate(2, Date.valueOf(entry.getDate()));
                        p.setString(3, entry.getParticulars());
                        p.setString(4, entry.getCurrency());
                        p.setString(5, entry.getType());
                        p.executeUpdate();
                        try (ResultSet keys = p.getGeneratedKeys()) {
                            if (!keys.next()) throw new SQLException("Could not create journal entry.");
                            id = keys.getLong(1);
                        }
                    }
                }
                insertLines(c, id, entry);
                c.commit();
                return id;
            } catch (SQLException ex) {
                c.rollback();
                throw ex;
            } finally {
                c.setAutoCommit(true);
            }
        }
    }

    private void verifyOwnedAccounts(Connection c, long userId, List<JournalLine> lines) throws SQLException {
        java.util.Set<Long> accountIds = new java.util.HashSet<>();
        for (JournalLine line : lines) accountIds.add(line.getAccount().getId());
        if (accountIds.isEmpty()) throw new SQLException("A journal entry must contain lines.");
        String placeholders = String.join(",", java.util.Collections.nCopies(accountIds.size(), "?"));
        try (PreparedStatement p = c.prepareStatement(
                "SELECT COUNT(*) FROM ledger_accounts WHERE user_id=? AND id IN (" + placeholders + ")")) {
            p.setLong(1, userId);
            int index = 2;
            for (Long accountId : accountIds) p.setLong(index++, accountId);
            try (ResultSet r = p.executeQuery()) {
                if (!r.next() || r.getInt(1) != accountIds.size()) {
                    throw new SQLException("Selected ledger accounts are not available for this user.");
                }
            }
        }
    }

    List<LedgerLine> ledger(long userId, long accountId) throws SQLException {
        String sql = "SELECT j.entry_date,j.particulars,j.currency,a.account_name,a.account_type,l.debit,l.credit "
                + "FROM journal_entry_lines l JOIN journal_entries j ON j.id=l.journal_entry_id "
                + "JOIN ledger_accounts a ON a.id=l.ledger_account_id "
                + "WHERE j.user_id=? AND a.user_id=? AND a.id=? ORDER BY j.entry_date,j.id,l.id";
        List<LedgerLine> result = new ArrayList<>();
        try (Connection c = Database.getConnection(); PreparedStatement p = c.prepareStatement(sql)) {
            p.setLong(1, userId);
            p.setLong(2, userId);
            p.setLong(3, accountId);
            try (ResultSet r = p.executeQuery()) {
                java.util.Map<String, java.math.BigDecimal> balances = new java.util.HashMap<>();
                while (r.next()) {
                    String type = r.getString(5);
                    String currency = r.getString(3);
                    java.math.BigDecimal debit = r.getBigDecimal(6);
                    java.math.BigDecimal credit = r.getBigDecimal(7);
                    boolean debitNormal = type.equals("ASSET") || type.equals("EXPENSE");
                    java.math.BigDecimal balance = balances.getOrDefault(currency, java.math.BigDecimal.ZERO);
                    balance = debitNormal ? balance.add(debit).subtract(credit) : balance.add(credit).subtract(debit);
                    balances.put(currency, balance);
                    result.add(new LedgerLine(r.getDate(1).toLocalDate(), r.getString(4), r.getString(2),
                            currency, debit, credit, balance));
                }
            }
        }
        return result;
    }

                     List<JournalLine> lines) throws SQLException {
        String description = particulars == null ? "" : particulars.trim();
        String curr = currency == null ? "" : currency.trim().toUpperCase(java.util.Locale.ROOT);
        if (date == null) throw new IllegalArgumentException("Choose an entry date.");
        if (description.isEmpty() || description.length() > 500) throw new IllegalArgumentException("Particulars are required (maximum 500 characters).");
        if (!curr.matches("[A-Z]{3}")) throw new IllegalArgumentException("Currency must be a three-letter code, such as USD.");
        if (lines == null || lines.size() < 2) throw new IllegalArgumentException("Add at least two journal lines.");
        BigDecimal debitTotal = BigDecimal.ZERO;
        BigDecimal creditTotal = BigDecimal.ZERO;
        for (JournalLine line : lines) {
            if (line == null || line.getAccount() == null) throw new IllegalArgumentException("Select an account for every line.");
            BigDecimal debit = line.getDebit();
            BigDecimal credit = line.getCredit();

            validateAmount(credit);

            creditTotal = creditTotal.add(credit);
        }

        }

import java.sql.SQLException;
import java.util.Locale;
import java.util.regex.Pattern;

public final class AuthService {
    private static final Pattern USERNAME = Pattern.compile("[A-Za-z0-9_]{3,32}");
    private static final Pattern EMAIL = Pattern.compile("^[^\\s@]+@[^\\s@]+\\.[^\\s@]+$");
    private final UserRepository users = new UserRepository();
    private final PasswordHasher hasher = new PasswordHasher();

    public User register(String username, String email, char[] password, char[] confirmation)
            throws SQLException {
        String cleanUsername = username == null ? "" : username.trim();
        String cleanEmail = email == null ? "" : email.trim().toLowerCase(Locale.ROOT);
        if (!USERNAME.matcher(cleanUsername).matches()) {
            throw new IllegalArgumentException("Username must be 3–32 characters using letters, numbers, or underscore.");
        }
        if (cleanEmail.length() > 254 || !EMAIL.matcher(cleanEmail).matches()) {
            throw new IllegalArgumentException("Enter a valid email address.");
        }
        if (password == null || password.length < 10) {
            throw new IllegalArgumentException("Password must contain at least 10 characters.");
        }
        if (!java.util.Arrays.equals(password, confirmation)) {
            throw new IllegalArgumentException("Passwords do not match.");
        }
        return users.register(cleanUsername, cleanEmail, hasher.hash(password));
    }

    public User authenticate(String login, char[] password) throws SQLException {
        String identifier = login == null ? "" : login.trim();
        String hash = users.passwordHashFor(identifier);
        boolean valid = hash != null && password != null && hasher.verify(password, hash);
        if (!valid) throw new IllegalArgumentException("Invalid username/email or password.");
        return users.findByLogin(identifier);
    }

    public User updateEmail(User user, String email, char[] currentPassword) throws SQLException {
        String cleanEmail = email == null ? "" : email.trim().toLowerCase(Locale.ROOT);
        if (cleanEmail.length() > 254 || !EMAIL.matcher(cleanEmail).matches()) {
            throw new IllegalArgumentException("Enter a valid email address.");
        }
        String storedHash = users.passwordHashFor(user.getId());
        if (storedHash == null || currentPassword == null || !hasher.verify(currentPassword, storedHash)) {
            throw new IllegalArgumentException("Current password is incorrect.");
        }
        return users.updateEmail(user.getId(), cleanEmail);
    }
}

public final class Database {
    private static final String DEFAULT_URL = "";
    private static final String DEFAULT_USER = "";

    private Database() {}

    public static Connection getConnection() throws SQLException {
        String password = System.getenv("ENTRI_DB_PASSWORD");
        if (password == null || password.isBlank()) {
            throw new SQLException("Database password is not configured. Set ENTRI_DB_PASSWORD.");
        }
        Properties config = loadLocalConfig();
        String url = environmentOrConfig(config, "ENTRI_DB_URL", "entri.db.url", DEFAULT_URL);
        String user = environmentOrConfig(config, "ENTRI_DB_USER", "entri.db.user", DEFAULT_USER);
        if (url.isBlank() || user.isBlank()) {
            throw new SQLException("Supabase database connection is not configured. Set ENTRI_DB_URL "
                    + "and ENTRI_DB_USER using the connection details from your Supabase project.");
        }
        try {
            return DriverManager.getConnection(url, user, password);
        } catch (SQLException ex) {
            throw new SQLException("Could not connect to Supabase PostgreSQL. Check the project connection "
                    + "URL, database username/password, network access, and that database\\entri_schema.sql "
                    + "has been run. SQLSTATE " + ex.getSQLState() + ".", ex);
        }
    }

    public static void testConnection() throws SQLException {
        try (Connection ignored = getConnection()) {
            // Opening a connection is the startup connectivity check.
        }
    }

    private static String environmentOrConfig(Properties config, String environment, String property, String fallback) {
        String value = System.getenv(environment);
        if (value != null && !value.isBlank()) return value.trim();
        value = config.getProperty(property);
        return value == null || value.isBlank() ? fallback : value.trim();
    }

    private static Properties loadLocalConfig() throws SQLException {
        Properties properties = new Properties();
        Path path = Path.of("config.properties");
        if (!Files.exists(path)) return properties;
        try (InputStream input = Files.newInputStream(path)) {
            properties.load(input);
            return properties;
        } catch (IOException ex) {
            throw new SQLException("Could not read config.properties.", ex);
        }
    }

package main.java.com.entri;

import java.math.BigDecimal;
import java.time.LocalDate;
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

public final class JournalEntry {
    private final long id;
    private final LocalDate date;
    private final String particulars;
    private final String currency;
    private final String type;
    private final List<JournalLine> lines;

    public JournalEntry(long id, LocalDate date, String particulars, String currency, String type,
                        Account debitAccount, Account creditAccount, BigDecimal amount) {
        this(id, date, particulars, currency, type,
                createLines(debitAccount, creditAccount, amount));
    }

    public JournalEntry(long id, LocalDate date, String particulars, String currency, String type,
                        List<JournalLine> lines) {
        this.id = id;
        this.date = date;
        this.particulars = particulars;
        this.currency = currency;
        this.type = type;
        this.lines = Collections.unmodifiableList(new ArrayList<>(lines));
    }

    private static List<JournalLine> createLines(Account debitAccount, Account creditAccount,
                                                  BigDecimal amount) {
        List<JournalLine> lines = new ArrayList<>();
        lines.add(new JournalLine(debitAccount, amount, BigDecimal.ZERO));
        lines.add(new JournalLine(creditAccount, BigDecimal.ZERO, amount));
        return lines;
    }

    public long getId() { return id; }
    public LocalDate getDate() { return date; }
    public String getParticulars() { return particulars; }
    public String getCurrency() { return currency; }
    public String getType() { return type; }
    public List<JournalLine> getLines() { return lines; }
    public BigDecimal getDebitTotal() {
        BigDecimal total = BigDecimal.ZERO;
        for (JournalLine line : lines) {
            total = total.add(line.getDebit());
        }
        return total;
    }
    public BigDecimal getCreditTotal() {
        BigDecimal total = BigDecimal.ZERO;
        for (JournalLine line : lines) {
            total = total.add(line.getCredit());
        }
        return total;
    }
    public BigDecimal getAmount() { return getDebitTotal(); }
    public Account getDebitAccount() {
        for (JournalLine line : lines) {
            if (line.getDebit().signum() > 0) {
                return line.getAccount();
            }
        }
        return null;
    }
    public Account getCreditAccount() {
        for (JournalLine line : lines) {
            if (line.getCredit().signum() > 0) {
                return line.getAccount();
            }
        }
        return null;
    }
}

    private static int compareAmounts(String first, String second) {
        try {
            return new BigDecimal(first.replaceAll("[^0-9.\\-]", ""))
                    .compareTo(new BigDecimal(second.replaceAll("[^0-9.\\-]", "")));
        } catch (NumberFormatException ex) {
            return first.compareTo(second);
        }
    }

    @Override public void reload() {
        String filter = search.getText();
        LocalDate start = fromDate.getValue();
        LocalDate end = toDate.getValue();
        if (start != null && end != null && start.isAfter(end)) {
            app.showError("Invalid date range", "The start date must be on or before the end date.");
            return;
        }
        totals.setText("Loading journal entries...");
        app.async(() -> app.accounting().entries(user.getId(), filter, start, end), entries -> {
            table.setItems(FXCollections.observableArrayList(entries));
            Map<String, BigDecimal[]> totalsByCurrency = new TreeMap<>();
            for (JournalEntry entry : entries) {
                BigDecimal[] value = totalsByCurrency.get(entry.getCurrency());
                if (value == null) {
                    value = new BigDecimal[]{BigDecimal.ZERO, BigDecimal.ZERO};
                    totalsByCurrency.put(entry.getCurrency(), value);
                }
                value[0] = value[0].add(entry.getDebitTotal());
                value[1] = value[1].add(entry.getCreditTotal());
            }
            List<String> values = new ArrayList<>();
            for (Map.Entry<String, BigDecimal[]> item : totalsByCurrency.entrySet()) {
                BigDecimal[] amount = item.getValue();
                values.add(item.getKey() + " — Debit: " + app.formatMoney(amount[0])
                        + " / Credit: " + app.formatMoney(amount[1]));
            }
            totals.setText("Display preference " + app.currencySymbol()
                    + " (amounts grouped by saved currency; no conversion) — "
                    + (values.isEmpty() ? "0" : String.join("    ", values)));
        }, ex -> app.showError("Could not load journal entries", MainApp.safeMessage(ex)));
    }

    private static LineEditor createLine(List<Account> accounts, JournalLine existing,
                                         ObservableList<LineEditor> lines, Runnable changed, Runnable render) {

    private static void updateBalance(List<LineEditor> lines, Label totalLabel, Label status,
                                      String currencyCode) {
        BigDecimal debit = BigDecimal.ZERO;
        BigDecimal credit = BigDecimal.ZERO;
        boolean valid = true;
        for (LineEditor line : lines) {
            debit = debit.add(line.value(line.debit));
            credit = credit.add(line.value(line.credit));
            valid &= line.isInputValid();
        }
        totalLabel.setText("Debit total: " + CurrencyFormatter.format(debit, currencyCode)
                + "     Credit total: " + CurrencyFormatter.format(credit, currencyCode)
                + "     Difference: " + CurrencyFormatter.format(debit.subtract(credit).abs(), currencyCode));
        boolean balanced = valid && debit.signum() > 0 && debit.compareTo(credit) == 0;
        status.setText(balanced ? "Balanced — ready to post"
                : valid ? "Unbalanced — debits must equal credits"
                : "Invalid line amount — use non-negative decimals with up to four places.");
        status.setStyle("-fx-font-weight: bold; -fx-text-fill: "
                + (balanced ? EntriTheme.SUCCESS : EntriTheme.ERROR) + ";");
    }

    private static List<JournalLine> collectLines(List<LineEditor> editors) {
        List<JournalLine> lines = new ArrayList<>();
        for (LineEditor editor : editors) {
            Account account = editor.account.getValue();
            if (account == null) throw new IllegalArgumentException("Select an account for every line.");
            BigDecimal debit = parseAmount(editor.debit.getText());
            BigDecimal credit = parseAmount(editor.credit.getText());
            if (debit.signum() == 0 && credit.signum() == 0) {
                throw new IllegalArgumentException("Every line must contain a debit or a credit amount.");
            }
            if (debit.signum() > 0 && credit.signum() > 0) {
                throw new IllegalArgumentException("A line cannot contain both debit and credit amounts.");
            }
            lines.add(new JournalLine(account, debit, credit));
        }
        if (lines.size() < 2) throw new IllegalArgumentException("At least two journal lines are required.");
        BigDecimal debit = BigDecimal.ZERO;
        BigDecimal credit = BigDecimal.ZERO;
        for (JournalLine line : lines) {
            debit = debit.add(line.getDebit());
            credit = credit.add(line.getCredit());
        }
        if (debit.signum() <= 0 || debit.compareTo(credit) != 0) {
            throw new IllegalArgumentException("Entry is unbalanced. Debit and credit totals must match and be positive.");
        }
        return Collections.unmodifiableList(lines);
    }

    private static BigDecimal parseAmount(String input) {
        if (input == null || input.isBlank()) return BigDecimal.ZERO;
        try {
            BigDecimal amount = new BigDecimal(input.trim());
            if (amount.signum() < 0 || amount.scale() > 4 || amount.precision() > 19
                    || amount.compareTo(new BigDecimal("1000000000000000")) >= 0) {
                throw new IllegalArgumentException("Amounts must be non-negative with up to four decimal places.");
            }
            return amount;
        } catch (NumberFormatException ex) {
            throw new IllegalArgumentException("Enter valid decimal amounts, for example 125.50.");
        }
    }

    private static final class LineEditor {
        final ComboBox<Account> account = new ComboBox<>();
        final TextField debit = new TextField();
        final TextField credit = new TextField();
        final Button removeButton = new Button("Remove");
        final HBox row;

        LineEditor(List<Account> accounts, JournalLine existing, Runnable changed, Runnable removeAction) {
            account.setItems(FXCollections.observableArrayList(accounts));
            account.setConverter(new StringConverter<>() {
                @Override public String toString(Account value) { return value == null ? "" : value.toString(); }
                @Override public Account fromString(String value) { return null; }
            });
            account.setMaxWidth(Double.MAX_VALUE);
            HBox.setHgrow(account, Priority.ALWAYS);
            debit.setPromptText("0.00");
            credit.setPromptText("0.00");
            debit.setPrefWidth(110);
            debit.setMinWidth(75);
            debit.setMaxWidth(180);
            credit.setPrefWidth(110);
            credit.setMinWidth(75);
            credit.setMaxWidth(180);
            HBox.setHgrow(debit, Priority.SOMETIMES);
            HBox.setHgrow(credit, Priority.SOMETIMES);
            removeButton.setTooltip(new Tooltip("Remove this line"));
            removeButton.setOnAction(e -> removeAction.run());
            row = new HBox(10, account, debit, credit, removeButton);
            row.setAlignment(javafx.geometry.Pos.CENTER_LEFT);
            if (existing != null) {
                Account existingAccount = null;
                for (Account possibleAccount : accounts) {
                    if (possibleAccount.getId() == existing.getAccount().getId()) {
                        existingAccount = possibleAccount;
                        break;
                    }
                }
                account.setValue(existingAccount);
                if (existing.getDebit().signum() > 0) debit.setText(existing.getDebit().toPlainString());
                if (existing.getCredit().signum() > 0) credit.setText(existing.getCredit().toPlainString());
            }
            account.valueProperty().addListener((o, old, value) -> changed.run());
            debit.textProperty().addListener((o, old, value) -> changed.run());
            credit.textProperty().addListener((o, old, value) -> changed.run());
        }

        BigDecimal value(TextField field) {
            try { return field.getText() == null || field.getText().isBlank()
                    ? BigDecimal.ZERO : new BigDecimal(field.getText().trim()); }
            catch (NumberFormatException ex) { return BigDecimal.ZERO; }
        }

        boolean isInputValid() {
            if (!validAmount(debit.getText()) || !validAmount(credit.getText())) return false;
            BigDecimal debitValue = value(debit);
            BigDecimal creditValue = value(credit);
            return debitValue.signum() == 0 || creditValue.signum() == 0;
        }

        private static boolean validAmount(String text) {
            if (text == null || text.isBlank()) return true;
            try {
                BigDecimal value = new BigDecimal(text.trim());
                return value.signum() >= 0 && value.scale() <= 4 && value.precision() <= 19
                        && value.compareTo(new BigDecimal("1000000000000000")) < 0;
            } catch (NumberFormatException ex) {
                return false;
            }
        }
    }

import java.math.BigDecimal;

public final class JournalLine {
    private final Account account;
    private final BigDecimal debit;
    private final BigDecimal credit;

    public JournalLine(Account account, BigDecimal debit, BigDecimal credit) {
        if (account == null || debit == null || credit == null
                || debit.signum() < 0 || credit.signum() < 0
                || debit.signum() > 0 && credit.signum() > 0) {
            throw new IllegalArgumentException("Invalid journal line.");
        }
        this.account = account;
        this.debit = debit;
        this.credit = credit;
    }

    public Account getAccount() { return account; }
    public BigDecimal getDebit() { return debit; }
    public BigDecimal getCredit() { return credit; }
}

    private void filterAccounts() {
        Account selected = accounts.getValue();
        String query = accountSearch.getText() == null ? ""
                : accountSearch.getText().trim().toLowerCase(java.util.Locale.ROOT);
        List<Account> matches = new ArrayList<>();
        for (Account account : allAccounts) {
            if (account.getName().toLowerCase(java.util.Locale.ROOT).contains(query)
                    || account.getCode().toLowerCase(java.util.Locale.ROOT).contains(query)) {
                matches.add(account);
            }
        }
        accounts.setItems(FXCollections.observableArrayList(matches));
        if (selected != null) {
            Account visible = findAccount(matches, selected.getId());
            if (visible != null) {
                accounts.getSelectionModel().select(visible);
            } else {
                accounts.getSelectionModel().clearSelection();
                table.getItems().clear();
            }
        } else if (!matches.isEmpty()) {
            accounts.getSelectionModel().selectFirst();
        }
    }

    private void applyFilter() {
        String query = search.getText() == null ? "" : search.getText().trim().toLowerCase(java.util.Locale.ROOT);
            List<AccountingRepository.LedgerLine> visible = new ArrayList<>();
            for (AccountingRepository.LedgerLine row : allRows) {
                if (row.explanation.toLowerCase(java.util.Locale.ROOT).contains(query)) {
                    visible.add(row);
                }
            }
            table.setItems(FXCollections.observableArrayList(visible));
            List<TAccountRow> debitRows = new ArrayList<>();
            List<TAccountRow> creditRows = new ArrayList<>();
            Map<String, BigDecimal[]> totalsByCurrency = new TreeMap<>();
            for (AccountingRepository.LedgerLine row : visible) {
                if (row.debit.signum() > 0) debitRows.add(new TAccountRow(row, row.debit));
                if (row.credit.signum() > 0) creditRows.add(new TAccountRow(row, row.credit));
                BigDecimal[] total = totalsByCurrency.get(row.currency);
                if (total == null) {
                    total = new BigDecimal[]{BigDecimal.ZERO, BigDecimal.ZERO};
                    totalsByCurrency.put(row.currency, total);
                }
                total[0] = total[0].add(row.debit);
                total[1] = total[1].add(row.credit);
            }
            debitTable.setItems(FXCollections.observableArrayList(debitRows));
            creditTable.setItems(FXCollections.observableArrayList(creditRows));

            List<String> summaries = new ArrayList<>();
            for (Map.Entry<String, BigDecimal[]> item : totalsByCurrency.entrySet()) {
                BigDecimal[] total = item.getValue();
                summaries.add(item.getKey() + " — Debit: " + fmt(total[0])
                        + "    Credit: " + fmt(total[1]));
            }
            if (summaries.isEmpty()) {
                totals.setText("No transactions for this account.");
                debitSideTotals.setText("Debit total: 0");
                creditSideTotals.setText("Credit total: 0");
                return;
            }

            Map<String, BigDecimal> endingByCurrency = new TreeMap<>();
            for (AccountingRepository.LedgerLine row : allRows) {
                endingByCurrency.put(row.currency, row.balance);
            }
            List<String> ending = new ArrayList<>();
            for (Map.Entry<String, BigDecimal> item : endingByCurrency.entrySet()) {
                ending.add(item.getKey() + " ending balance: " + fmt(item.getValue()));
            }
            totals.setText("Filtered debit / credit totals: " + String.join("       ", summaries)
                    + "       " + String.join("       ", ending));
            debitSideTotals.setText("Debit total by saved currency: "
                    + sideTotals(debitRows));
            creditSideTotals.setText("Credit total by saved currency: "
                    + sideTotals(creditRows));
    }

    private String sideTotals(List<TAccountRow> rows) {
        Map<String, BigDecimal> amounts = new TreeMap<>();
        for (TAccountRow row : rows) {
            BigDecimal total = amounts.get(row.line.currency);
            if (total == null) total = BigDecimal.ZERO;
            amounts.put(row.line.currency, total.add(row.amount));
        }
        List<String> values = new ArrayList<>();
        for (Map.Entry<String, BigDecimal> item : amounts.entrySet()) {
            values.add(item.getKey() + " " + fmt(item.getValue()));
        }
        return values.isEmpty() ? "0" : String.join("    ", values);
    }

            this.amount = amount;
        }
    }

    <T> void async(Callable<T> work, Consumer<T> success, Consumer<Throwable> failure) {
        Task<T> task = new Task<>() {
            @Override protected T call() throws Exception { return work.call(); }
        };
        task.setOnSucceeded(e -> success.accept(task.getValue()));
        task.setOnFailed(e -> failure.accept(task.getException()));
        Thread thread = new Thread(task, "entri-background-task");
        thread.setDaemon(true);
        thread.start();
    }

    private static void arrangePreviewCards(GridPane grid, List<Node> cards, int columns) {
        grid.getChildren().clear();
        grid.getColumnConstraints().clear();
        grid.getRowConstraints().clear();
        for (int column = 0; column < columns; column++) {
            ColumnConstraints constraint = new ColumnConstraints();
            constraint.setPercentWidth(100.0 / columns);
            constraint.setHgrow(Priority.ALWAYS);
            grid.getColumnConstraints().add(constraint);
        }
        if (columns == 1) {
            for (int row = 0; row < cards.size(); row++) {
                Node card = cards.get(row);
                GridPane.setHgrow(card, Priority.ALWAYS);
                GridPane.setVgrow(card, Priority.ALWAYS);
                grid.add(card, 0, row);
            }
        } else {
            for (int column = 0; column < 2; column++) {
                Node card = cards.get(column);
                GridPane.setHgrow(card, Priority.ALWAYS);
                GridPane.setVgrow(card, Priority.ALWAYS);
                grid.add(card, column, 0);
            }
            for (int row = 1; row < cards.size() - 1; row++) {
                Node card = cards.get(row + 1);
                GridPane.setHgrow(card, Priority.ALWAYS);
                GridPane.setVgrow(card, Priority.ALWAYS);
                grid.add(card, 0, row, 2, 1);
            }
        }
        int rows = columns == 1 ? cards.size() : cards.size() - 1;
        for (int row = 0; row < rows; row++) {
            RowConstraints constraint = new RowConstraints();
            constraint.setVgrow(Priority.ALWAYS);
            constraint.setMinHeight(row == 0 ? 260 : 320);
            grid.getRowConstraints().add(constraint);
        }
    }

    private TableRow<String[]> previewTableRow(int rowCount) {
        TableRow<String[]> row = new TableRow<>();
        Runnable updateStyle = () -> {
            String[] item = row.getItem();
            if (item == null) {
                row.setStyle("");
                return;
            }
            boolean total = row.getIndex() == rowCount - 1
                    && "TOTAL".equalsIgnoreCase(item[0]);
            row.setStyle(total
                    ? "-fx-background-color: " + EntriTheme.IVORY + "; -fx-font-weight: bold; -fx-border-color: "
                            + EntriTheme.BORDER + " transparent transparent transparent;"
                    : row.getIndex() % 2 == 0
                            ? "-fx-background-color: white;"
                            : "-fx-background-color: #FFFDF5;");
        };
        row.itemProperty().addListener((observable, previous, current) -> updateStyle.run());
        row.indexProperty().addListener((observable, previous, current) -> updateStyle.run());
        return row;
    }

    private void handleDashboardShortcut(KeyEvent event) {
        if (new KeyCodeCombination(KeyCode.N, KeyCombination.SHORTCUT_DOWN).match(event)) {
            navigate("journal");
            journal.addNewEntry();
            event.consume();
        } else if (new KeyCodeCombination(KeyCode.F, KeyCombination.SHORTCUT_DOWN).match(event)) {
            Node activePage = pageScroller.getContent();
            if (activePage == journal) {
                journal.focusSearch();
            } else if (activePage == ledger) {
                ledger.focusSearch();
            } else if (activePage == recent) {
                recent.focusSearch();
            } else if (activePage == dashboard) {
                navigate("journal");
                journal.focusSearch();
            }
            event.consume();
        }

    private void loadCurrencyPreference(long userId) {
        async(() -> settings.getCurrency(userId), savedCurrency -> {
            if (currentUser == null || currentUser.getId() != userId) return;
            if (CurrencyFormatter.isSupported(savedCurrency)) {
                currencyCode = savedCurrency;
            }
            showDashboard();
        }, error -> {
            if (currentUser == null || currentUser.getId() != userId) return;
            showDashboard();
            showError("Could not load currency preference",
                    safeMessage(error) + "\n\nRun database\\entri_schema.sql in the Supabase SQL Editor "
                            + "to add the user settings table.");
        });
    }

    private void changeCurrency(String newCurrency) {
        if (currentUser == null || !CurrencyFormatter.isSupported(newCurrency)
                || newCurrency.equals(currencyCode)) {
            return;
        }

        String oldCurrency = currencyCode;
        long userId = currentUser.getId();
        Menu selectedMenu = currencyMenu;
        currencyCode = newCurrency;
        updateCurrencyMenu();
        refreshCurrencyDisplays();
        selectedMenu.setDisable(true);

        async(() -> {
            settings.saveCurrency(userId, newCurrency);
            return null;
        }, ignored -> {
            if (currencyMenu == selectedMenu) {
                currencyMenu.setDisable(false);
            }
        }, error -> {
            if (currencyMenu == selectedMenu) {
                currencyMenu.setDisable(false);
            }
            if (currentUser != null && currentUser.getId() == userId) {
                currencyCode = oldCurrency;
                updateCurrencyMenu();
                refreshCurrencyDisplays();
            }
            showError("Could not save currency preference",
                    safeMessage(error) + "\n\nRun database\\entri_schema.sql in the Supabase SQL Editor "
                            + "to add the user settings table.");
        });
    }

    private void updateCurrencyMenu() {
        if (currencyMenu != null) {
            currencyMenu.setText("Currency display: " + currencySymbol());
        }
    }

    private void navigate(String target) {
        if (currentUser == null || shell == null) { showLogin(false, null); return; }
        Node section;
        if ("journal".equals(target)) {
            section = journal;
        } else if ("ledger".equals(target)) {
            section = ledger;
        } else if ("worksheet".equals(target)) {
            section = worksheet;
        } else if ("recent".equals(target)) {
            section = recent;
        } else {
            section = dashboard;
            target = "dashboard";
        }
        pageScroller.setContent(section);
        for (Node node : sidebar.lookupAll(".button")) {
            if (node instanceof Button) {
                Button button = (Button) node;
                boolean active = target.equals(button.getUserData());
                button.setStyle("-fx-background-color: " + (active ? EntriTheme.IVORY : "transparent")
                        + "; -fx-text-fill: " + EntriTheme.OLIVE
                        + "; -fx-font-weight: bold; -fx-padding: 10 12; -fx-background-radius: 7;");
            }
        }
        if (section instanceof AccountingSection) {
            ((AccountingSection) section).reload();
        }
        if ("worksheet".equals(target)) recordRecent("WORKSHEET", 0, "12-Column Worksheet");
    }

    private Label totalsByCurrency(List<JournalEntry> entries) {
        List<JournalEntry> shown = firstEntries(entries, 5);
        Map<String, BigDecimal[]> sums = new TreeMap<>();
        for (JournalEntry entry : shown) {
            BigDecimal[] value = sums.get(entry.getCurrency());
            if (value == null) {
                value = new BigDecimal[]{BigDecimal.ZERO, BigDecimal.ZERO};
                sums.put(entry.getCurrency(), value);
            }
            value[0] = value[0].add(entry.getDebitTotal());
            value[1] = value[1].add(entry.getCreditTotal());
        }
        List<String> values = new ArrayList<>();
        for (Map.Entry<String, BigDecimal[]> item : sums.entrySet()) {
            BigDecimal[] value = item.getValue();
            values.add(item.getKey() + " debit " + fmt(value[0]) + " / credit " + fmt(value[1]));
        }
        Label result = new Label("Preview totals by currency: "
                + (values.isEmpty() ? "0" : String.join("     ", values)));
        EntriTheme.muted(result);
        return result;
    }

    private static void arrangeGrid(GridPane grid, List<Node> items, int columns, boolean growRows) {
        grid.getChildren().clear();
        grid.getColumnConstraints().clear();
        grid.getRowConstraints().clear();
        for (int column = 0; column < columns; column++) {
            ColumnConstraints constraint = new ColumnConstraints();
            constraint.setPercentWidth(100.0 / columns);
            constraint.setHgrow(Priority.ALWAYS);
            grid.getColumnConstraints().add(constraint);
        }

        for (int index = 0; index < items.size(); index++) {
            int row = index / columns;
            int column = index % columns;
            grid.add(items.get(index), column, row);
        }
        if (growRows) {
            int rowCount = (items.size() + columns - 1) / columns;
            for (int row = 0; row < rowCount; row++) {
                RowConstraints constraint = new RowConstraints();
                constraint.setVgrow(Priority.ALWAYS);
                constraint.setMinHeight(250);
                grid.getRowConstraints().add(constraint);
            }
        }
    }

    private void rearrangeCards() {
        if (summaryGrid == null || previewGrid == null || cards.getWidth() <= 0) return;
        int summaryColumns = cards.getWidth() >= 1050 ? 3 : cards.getWidth() >= 700 ? 2 : 1;
        int previewColumns = cards.getWidth() >= 900 ? 2 : 1;
        arrangeGrid(summaryGrid, summaryCards, summaryColumns, false);
        arrangePreviewGrid(previewGrid, previewCards, previewColumns);
    }

    private static void arrangePreviewGrid(GridPane grid, List<Node> cards, int columns) {
        grid.getChildren().clear();
        grid.getColumnConstraints().clear();
        grid.getRowConstraints().clear();
        for (int column = 0; column < columns; column++) {
            ColumnConstraints constraint = new ColumnConstraints();
            constraint.setPercentWidth(100.0 / columns);
            constraint.setHgrow(Priority.ALWAYS);
            grid.getColumnConstraints().add(constraint);
        }

        if (columns == 1) {
            for (int row = 0; row < cards.size(); row++) {
                GridPane.setHgrow(cards.get(row), Priority.ALWAYS);
                GridPane.setVgrow(cards.get(row), Priority.ALWAYS);
                grid.add(cards.get(row), 0, row);
            }
        } else {
            for (int column = 0; column < 2; column++) {
                GridPane.setHgrow(cards.get(column), Priority.ALWAYS);
                GridPane.setVgrow(cards.get(column), Priority.ALWAYS);
                grid.add(cards.get(column), column, 0);
            }
            for (int row = 1; row < cards.size() - 1; row++) {
                Node card = cards.get(row + 1);
                GridPane.setHgrow(card, Priority.ALWAYS);
                GridPane.setVgrow(card, Priority.ALWAYS);
                grid.add(card, 0, row, 2, 1);
            }
        }

        int rows = columns == 1 ? cards.size() : cards.size() - 1;
        for (int row = 0; row < rows; row++) {
            RowConstraints constraint = new RowConstraints();
            constraint.setVgrow(Priority.ALWAYS);
            constraint.setMinHeight(row == 0 ? 260 : 320);
            grid.getRowConstraints().add(constraint);
        }
    }

    private static void cardChildren(VBox card, javafx.scene.Node... nodes) {
        card.getChildren().addAll(nodes);
    }

package main.java.com.entri;

import javax.crypto.SecretKeyFactory;
import javax.crypto.spec.PBEKeySpec;
import java.security.GeneralSecurityException;
import java.security.SecureRandom;
import java.util.Base64;

public final class PasswordHasher {
    private static final int ITERATIONS = 310_000;
    private static final int KEY_BITS = 256;
    private static final int SALT_BYTES = 16;
    private final SecureRandom random = new SecureRandom();

    public String hash(char[] password) {
        byte[] salt = new byte[SALT_BYTES];
        random.nextBytes(salt);
        byte[] derived = derive(password, salt, ITERATIONS);
        return ITERATIONS + ":" + Base64.getEncoder().encodeToString(salt)
                + ":" + Base64.getEncoder().encodeToString(derived);
    }

    public boolean verify(char[] password, String encoded) {
        try {
            String[] parts = encoded.split(":", -1);
            if (parts.length != 3) return false;
            int iterations = Integer.parseInt(parts[0]);
            if (iterations < 100_000 || iterations > 2_000_000) return false;
            byte[] salt = Base64.getDecoder().decode(parts[1]);
            byte[] expected = Base64.getDecoder().decode(parts[2]);
            return java.security.MessageDigest.isEqual(expected, derive(password, salt, iterations));
        } catch (IllegalArgumentException ex) {
            return false;
        }
    }

    private byte[] derive(char[] password, byte[] salt, int iterations) {
        PBEKeySpec spec = new PBEKeySpec(password, salt, iterations, KEY_BITS);
        try {
            return SecretKeyFactory.getInstance("PBKDF2WithHmacSHA256").generateSecret(spec).getEncoded();
        } catch (GeneralSecurityException ex) {
            throw new IllegalStateException("PBKDF2-HMAC-SHA256 is unavailable.", ex);
        } finally {
            spec.clearPassword();
        }
    }
}

        List<RecentView> matches = new ArrayList<>();

            if (view.getName().toLowerCase(java.util.Locale.ROOT).contains(query)

                matches.add(view);
            }

        if (matches.isEmpty() && !query.isEmpty()) {
            table.setPlaceholder(new Label("No recent items match your search. Clear the search to see all recent views."));
        } else if (matches.isEmpty()) {
            table.setPlaceholder(new Label("Items you open will appear here. No recent views yet."));
        }
    }

import java.sql.*;

final class UserRepository {
    User register(String username, String email, String passwordHash) throws SQLException {
        String insertUser = "INSERT INTO users(username,email,password_hash) VALUES(?,?,?)";
        String[] names = {"Cash", "Accounts Receivable", "Supplies", "Equipment",
                "Accounts Payable", "Owner's Capital", "Service Revenue", "Rent Expense",
                "Utilities Expense"};
        String[] codes = {"1000", "1100", "1200", "1500", "2000", "3000", "4000", "5000", "5100"};
        String[] types = {"ASSET", "ASSET", "ASSET", "ASSET", "LIABILITY", "EQUITY",
                "REVENUE", "EXPENSE", "EXPENSE"};
        try (Connection c = Database.getConnection()) {
            c.setAutoCommit(false);
            try {
                long id;
                try (PreparedStatement p = c.prepareStatement(insertUser, Statement.RETURN_GENERATED_KEYS)) {
                    p.setString(1, username);
                    p.setString(2, email);
                    p.setString(3, passwordHash);
                    p.executeUpdate();
                    try (ResultSet keys = p.getGeneratedKeys()) {
                        if (!keys.next()) throw new SQLException("User creation did not return an ID.");
                        id = keys.getLong(1);
                    }
                }
                try (PreparedStatement p = c.prepareStatement(
                        "INSERT INTO ledger_accounts(user_id,account_code,account_name,account_type) VALUES(?,?,?,?)")) {
                    for (int i = 0; i < names.length; i++) {
                        p.setLong(1, id);
                        p.setString(2, codes[i]);
                        p.setString(3, names[i]);
                        p.setString(4, types[i]);
                        p.addBatch();
                    }
                    p.executeBatch();
                }
                User created = findById(c, id);
                c.commit();
                return created;
            } catch (SQLException ex) {
                c.rollback();
                if ("23505".equals(ex.getSQLState())) {
                    throw new IllegalArgumentException("That username or email is already registered.", ex);
                }
                throw ex;
            } finally {
                c.setAutoCommit(true);
            }
        }
    }

    String passwordHashFor(String login) throws SQLException {
        try (Connection c = Database.getConnection();
             PreparedStatement p = c.prepareStatement(
                     "SELECT password_hash FROM users WHERE username=? OR email=? LIMIT 1")) {
            p.setString(1, login);
            p.setString(2, login.toLowerCase(java.util.Locale.ROOT));
            try (ResultSet r = p.executeQuery()) {
                return r.next() ? r.getString(1) : null;
            }
        }
    }

    String passwordHashFor(long userId) throws SQLException {
        try (Connection c = Database.getConnection();
             PreparedStatement p = c.prepareStatement("SELECT password_hash FROM users WHERE id=?")) {
            p.setLong(1, userId);
            try (ResultSet r = p.executeQuery()) { return r.next() ? r.getString(1) : null; }
        }
    }

    User updateEmail(long userId, String email) throws SQLException {
        try (Connection c = Database.getConnection();
             PreparedStatement p = c.prepareStatement(
                     "UPDATE users SET email=?,updated_at=CURRENT_TIMESTAMP WHERE id=?")) {
            p.setString(1, email);
            p.setLong(2, userId);
            try {
                if (p.executeUpdate() != 1) throw new SQLException("Account could not be updated.");
            } catch (SQLException ex) {
                if ("23505".equals(ex.getSQLState())) {
                    throw new IllegalArgumentException("That email address is already in use.", ex);
                }
                throw ex;
            }
        }
        return findById(userId);
    }

    User findByLogin(String login) throws SQLException {
        try (Connection c = Database.getConnection();
             PreparedStatement p = c.prepareStatement(
                     "SELECT id,username,email,created_at FROM users WHERE username=? OR email=? LIMIT 1")) {
            p.setString(1, login);
            p.setString(2, login.toLowerCase(java.util.Locale.ROOT));
            try (ResultSet r = p.executeQuery()) {
                if (!r.next()) throw new SQLException("Authenticated user could not be loaded.");
                return new User(r.getLong("id"), r.getString("username"), r.getString("email"),
                        r.getTimestamp("created_at").toLocalDateTime());
            }
        }
    }

    private User findById(long id) throws SQLException {
        try (Connection c = Database.getConnection()) { return findById(c, id); }
    }

    private User findById(Connection c, long id) throws SQLException {
        try (PreparedStatement p = c.prepareStatement(
                "SELECT id,username,email,created_at FROM users WHERE id=?")) {
            p.setLong(1, id);
            try (ResultSet r = p.executeQuery()) {
                if (!r.next()) throw new SQLException("Newly created user could not be loaded.");
                return new User(r.getLong("id"), r.getString("username"), r.getString("email"),
                        r.getTimestamp("created_at").toLocalDateTime());
            }
        }
    }

package main.java.com.entri;

import java.math.BigDecimal;
import java.util.ArrayList;
import java.util.Arrays;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;
import java.util.TreeMap;

final class WorksheetCalculator {
    private WorksheetCalculator() {}

    static Result calculate(List<AccountingRepository.WorksheetRow> data) {
        boolean hasPostedEntries = false;
        Map<String, Aggregate> accounts = new LinkedHashMap<>();
        for (AccountingRepository.WorksheetRow row : data) {
            if (row.entryType != null && row.debit != null && row.credit != null) {
                hasPostedEntries = true;
            }
            String currency = row.currency == null ? "—" : row.currency;
            String key = row.id + ":" + currency;
            Aggregate account = accounts.get(key);
            if (account == null) {
                account = new Aggregate(row.name + " (" + currency + ")", row.type, currency);
                accounts.put(key, account);
            }
            if (row.entryType == null || row.debit == null || row.credit == null) continue;
            if ("ADJUSTMENT".equals(row.entryType)) {
                account.adjustDebit = account.adjustDebit.add(row.debit);
                account.adjustCredit = account.adjustCredit.add(row.credit);
            } else {
                account.trialDebit = account.trialDebit.add(row.debit);
                account.trialCredit = account.trialCredit.add(row.credit);
            }
        }

        List<DisplayRow> rows = new ArrayList<>();
        Map<String, BigDecimal[]> totalsByCurrency = new TreeMap<>();
        Map<String, BigDecimal> netIncomeByCurrency = new TreeMap<>();
        for (Aggregate account : accounts.values()) {
            BigDecimal[] sums = totalsByCurrency.get(account.currency);
            if (sums == null) {
                sums = new BigDecimal[12];
                Arrays.fill(sums, BigDecimal.ZERO);
                totalsByCurrency.put(account.currency, sums);
            }
            BigDecimal trialNet = account.trialDebit.subtract(account.trialCredit);
            BigDecimal adjustmentNet = account.adjustDebit.subtract(account.adjustCredit);
            BigDecimal adjustedNet = trialNet.add(adjustmentNet);
            DisplayRow row = new DisplayRow(account.name);
            putNet(row.values, 0, trialNet, isDebitNormal(account.type));
            row.values[2] = account.adjustDebit;
            row.values[3] = account.adjustCredit;
            putNet(row.values, 4, adjustedNet, isDebitNormal(account.type));
            if ("REVENUE".equals(account.type) || "EXPENSE".equals(account.type)) {
                putNet(row.values, 6, adjustedNet, isDebitNormal(account.type));
                BigDecimal currentIncome = netIncomeByCurrency.get(account.currency);
                if (currentIncome == null) currentIncome = BigDecimal.ZERO;
                netIncomeByCurrency.put(account.currency, currentIncome.add(adjustedNet.negate()));
            }
            if ("EQUITY".equals(account.type)) putNet(row.values, 8, adjustedNet, false);
            if ("ASSET".equals(account.type) || "LIABILITY".equals(account.type)
                    || "EQUITY".equals(account.type)) {
                putNet(row.values, 10, adjustedNet, isDebitNormal(account.type));
            }
            addValues(sums, row.values);
            rows.add(row);
        }

        for (Map.Entry<String, BigDecimal> incomeEntry : netIncomeByCurrency.entrySet()) {
            String currency = incomeEntry.getKey();
            BigDecimal netIncome = incomeEntry.getValue();
            DisplayRow incomeRow = new DisplayRow("Net Income / (Loss) (" + currency + ")");
            if (netIncome.signum() > 0) {
                incomeRow.values[6] = netIncome;
                incomeRow.values[9] = netIncome;
                incomeRow.values[11] = netIncome;
            } else if (netIncome.signum() < 0) {
                BigDecimal loss = netIncome.negate();
                incomeRow.values[7] = loss;
                incomeRow.values[8] = loss;
                incomeRow.values[10] = loss;
            }
            addValues(totalsByCurrency.get(currency), incomeRow.values);
            rows.add(incomeRow);
        }

        boolean balanced = true;
        for (BigDecimal[] sums : totalsByCurrency.values()) {
            if (sums[0].compareTo(sums[1]) != 0
                    || sums[2].compareTo(sums[3]) != 0
                    || sums[4].compareTo(sums[5]) != 0
                    || sums[6].compareTo(sums[7]) != 0
                    || sums[10].compareTo(sums[11]) != 0) {
                balanced = false;
                break;
            }
        }
        return new Result(rows, totalsByCurrency, hasPostedEntries, balanced);
    }

    private static void addValues(BigDecimal[] totals, BigDecimal[] values) {
        for (int i = 0; i < values.length; i++) totals[i] = totals[i].add(values[i]);
    }

    private static boolean isDebitNormal(String type) {
        return "ASSET".equals(type) || "EXPENSE".equals(type);
    }

    private static void putNet(BigDecimal[] values, int index, BigDecimal net, boolean debitNormal) {
        BigDecimal normal = debitNormal ? net : net.negate();
        if (normal.signum() > 0) {
            if (debitNormal) values[index] = normal;
            else values[index + 1] = normal;
        } else if (normal.signum() < 0) {
            if (debitNormal) values[index + 1] = normal.negate();
            else values[index] = normal.negate();
        }
    }

    static final class Result {
        final List<DisplayRow> rows;
        final Map<String, BigDecimal[]> totalsByCurrency;
        final boolean hasPostedEntries;
        final boolean balanced;

        Result(List<DisplayRow> rows, Map<String, BigDecimal[]> totalsByCurrency,
               boolean hasPostedEntries, boolean balanced) {
            this.rows = rows;
            this.totalsByCurrency = totalsByCurrency;
            this.hasPostedEntries = hasPostedEntries;
            this.balanced = balanced;
        }
    }

    static final class DisplayRow {
        final String name;
        final BigDecimal[] values = new BigDecimal[12];
        DisplayRow(String name) {
            this.name = name;
            Arrays.fill(values, BigDecimal.ZERO);
        }
    }

    private static final class Aggregate {
        final String name;
        final String type;
        final String currency;
        BigDecimal trialDebit = BigDecimal.ZERO;
        BigDecimal trialCredit = BigDecimal.ZERO;
        BigDecimal adjustDebit = BigDecimal.ZERO;
        BigDecimal adjustCredit = BigDecimal.ZERO;

        Aggregate(String name, String type, String currency) {
            this.name = name;
            this.type = type;
            this.currency = currency;
        }
    }
}

package main.java.com.entri;

import java.math.BigDecimal;
import java.util.Arrays;
import java.util.List;

public final class WorksheetCalculatorTest {
    public static void main(String[] args) {
        testBalancedWorksheetAndAdjustments();
        testNetLoss();
        testCurrenciesAreCheckedSeparately();
        System.out.println("WorksheetCalculatorTest passed.");
    }

    private static void testBalancedWorksheetAndAdjustments() {
        List<AccountingRepository.WorksheetRow> data = Arrays.asList(
                row(1, "Cash", "ASSET", "STANDARD", "PHP", "150", "0"),
                row(2, "Accounts Payable", "LIABILITY", "STANDARD", "PHP", "0", "50"),
                row(3, "Owner Capital", "EQUITY", "STANDARD", "PHP", "0", "50"),
                row(4, "Service Revenue", "REVENUE", "STANDARD", "PHP", "0", "80"),
                row(5, "Rent Expense", "EXPENSE", "STANDARD", "PHP", "30", "0"),
                row(5, "Rent Expense", "EXPENSE", "ADJUSTMENT", "PHP", "10", "0"),
                row(2, "Accounts Payable", "LIABILITY", "ADJUSTMENT", "PHP", "0", "10"));

        WorksheetCalculator.Result result = WorksheetCalculator.calculate(data);
        require(result.hasPostedEntries, "Posted journal entries should be detected.");
        require(result.balanced, "All worksheet groups should balance after adjustment: "
                + Arrays.toString(result.totalsByCurrency.get("PHP")));
        BigDecimal[] totals = result.totalsByCurrency.get("PHP");
        require(amount(totals[0], "180") && amount(totals[1], "180"),
                "Trial balance totals should be 180 on both sides.");
        require(amount(totals[2], "10") && amount(totals[3], "10"),
                "Adjustment totals should be 10 on both sides.");
        require(amount(totals[4], "190") && amount(totals[5], "190"),
                "Adjusted trial balance totals should be 190 on both sides.");
        require(amount(totals[6], "80") && amount(totals[7], "80"),
                "Income statement should balance after carrying 40 net income.");
        require(amount(totals[8], "0") && amount(totals[9], "90"),
                "Owner's equity should include capital and net income on the credit side.");
        require(amount(totals[10], "150") && amount(totals[11], "150"),
                "Balance sheet totals should include net income.");
        WorksheetCalculator.DisplayRow income = findRow(result.rows, "Net Income / (Loss) (PHP)");
        require(amount(income.values[6], "40") && amount(income.values[9], "40")
                        && amount(income.values[11], "40"),
                "Net income should appear in the income statement, owner's equity, and balance sheet.");
    }

    private static void testNetLoss() {
        List<AccountingRepository.WorksheetRow> data = Arrays.asList(
                row(1, "Cash", "ASSET", "STANDARD", "USD", "100", "0"),
                row(2, "Owner Capital", "EQUITY", "STANDARD", "USD", "0", "110"),
                row(3, "Service Revenue", "REVENUE", "STANDARD", "USD", "0", "20"),
                row(4, "Rent Expense", "EXPENSE", "STANDARD", "USD", "30", "0"));

        WorksheetCalculator.Result result = WorksheetCalculator.calculate(data);
        require(result.balanced, "A balanced trial balance with a net loss should remain balanced.");
        BigDecimal[] totals = result.totalsByCurrency.get("USD");
        require(amount(totals[6], "30") && amount(totals[7], "30"),
                "Income statement totals should reflect the loss.");
        require(amount(totals[8], "10") && amount(totals[9], "110"),
                "Net loss should reduce owner's equity.");
        require(amount(totals[10], "110") && amount(totals[11], "110"),
                "Net loss should be carried to the balance sheet.");
        WorksheetCalculator.DisplayRow loss = findRow(result.rows, "Net Income / (Loss) (USD)");
        require(amount(loss.values[7], "10") && amount(loss.values[8], "10")
                        && amount(loss.values[10], "10"),
                "Net loss should appear in the income statement, owner's equity, and balance sheet.");
    }

    private static void testCurrenciesAreCheckedSeparately() {
        List<AccountingRepository.WorksheetRow> data = Arrays.asList(
                row(1, "Cash", "ASSET", "STANDARD", "PHP", "100", "0"),
                row(2, "Owner Capital", "EQUITY", "STANDARD", "PHP", "0", "100"),
                row(3, "Cash", "ASSET", "STANDARD", "USD", "100", "0"),
                row(4, "Owner Capital", "EQUITY", "STANDARD", "USD", "0", "90"));

        WorksheetCalculator.Result result = WorksheetCalculator.calculate(data);
        require(result.totalsByCurrency.size() == 2, "Each currency should have separate worksheet totals.");
        require(!result.balanced, "An imbalance in either currency should mark the worksheet unbalanced.");
    }

    private static AccountingRepository.WorksheetRow row(long id, String name, String type,
                                                           String entryType, String currency,
                                                           String debit, String credit) {
        return new AccountingRepository.WorksheetRow(id, name, type, entryType, currency,
                new BigDecimal(debit), new BigDecimal(credit));
    }

    private static WorksheetCalculator.DisplayRow findRow(
            List<WorksheetCalculator.DisplayRow> rows, String name) {
        for (WorksheetCalculator.DisplayRow row : rows) {
            if (row.name.equals(name)) return row;
        }
        throw new AssertionError("Could not find worksheet row: " + name);
    }

    private static boolean amount(BigDecimal actual, String expected) {
        return actual.compareTo(new BigDecimal(expected)) == 0;
    }

    private static void require(boolean condition, String message) {
        if (!condition) throw new AssertionError(message);
    }
}
